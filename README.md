# 换网版定位孔相位校验

陶瓷贴花印刷换网版时的定位孔环相位校验工具。TypeScript + React + Vite 纯前端单页应用，
全部业务计算在浏览器本地完成，不调用任何在线服务，也不返回固定结果。

## 业务规则

- 分别录入参考版与待装版的**顺时针孔序**：仅允许 `A`、`B`、`C`、`D`，由普通空格
  （U+0020）分隔（忽略首尾及连续空格）；制表符、不换行空格、全角空格等均不是分隔符，
  每环 **4–48** 孔，两环孔数必须相同。
- 为每环选择一枚带向外箭头的起始孔；以各自箭头孔为索引 0，沿顺时针编号。
  零相位定义为两枚箭头重合。仅枚举顺时针相位，**禁止反转匹配**。
- 待装版顺时针移动 `k` 孔后，参考孔 `i` 对应待装孔 `(i-k+n) mod n`，其箭头移至参考环索引 `k`。
- 枚举 `k = 0..n-1`：
  - **恰有一个**逐孔相等的相位 → 显示「可装」、移动孔数、箭头新位置及全部孔对；
  - **没有完整匹配** → 显示「无匹配」，以错孔数最少、再以 `k` 最小选出诊断相位与首个错孔；
  - **多个完整匹配** → 列出全部 `k` 并显示「相位不唯一」。
- 「相位不唯一」时可录入**实物观察**逐步排除：每条观察由参考环索引与「看见/未见待装版箭头」
  组成，同一索引再次提交替换旧值；候选 `k` 即箭头新位置，看见则仅保留 `k = i`，未见则排除
  `k = i`。结果区随观察即时显示剩余相位：收敛为唯一时给出移动孔数与全部孔对，仍有多个时
  提示继续观察，全部排除时保留基础候选并提示观察与孔序不一致。参考环索引仅接受普通十进制
  整数（十六进制、指数等文本一律拒绝）；格式非法或索引越界仅在录入处反馈，
  不改变当前筛选结果。修改任一孔序或箭头起点会清除全部观察，也可一键清空。
- 非法字符、孔数越界、孔数不同，或编辑任一输入，都会立即清除旧结论（结论实时重算）。

## 本地开发

```bash
npm install
npm run dev          # 开发服务器
npm run test:unit    # Vitest：边界、索引方向、周期歧义、观察筛选
npm run test:e2e     # Playwright：录入、纠错、三类互斥结果、结果失效、观察排除
npm run build        # 类型检查 + 产物构建
```

## Docker

```bash
# 启动 web 服务（默认宿主端口 8080，可用 WEB_PORT 覆盖）
WEB_PORT=9000 docker compose up --build web

# 一次性验收：等待 web 就绪后运行 Vitest + Playwright，结束即退出
docker compose up --build --exit-code-from verify verify
```

- `web`：多阶段构建，nginx 托管 `dist` 静态产物，容器内端口 80。
- `verify`：基于官方 Playwright 镜像，先跑单元测试，再以 `http://web:80`
  为目标运行端到端验收。
